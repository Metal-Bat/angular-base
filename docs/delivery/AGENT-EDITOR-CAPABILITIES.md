## Precise producer handoff — APP-BE-019.UX01

1. **Authorized saved connection name.** AI `SelectQuery` has only page/size/search; it cannot resolve an exact selected key. Model metadata authorizes a connection but returns no display name. The generic connection read requires separate integration management access, which a workflows author need not possess. A selection made in the current picker retains its label off-page; a newly opened saved agent cannot reliably name an off-page connection. Do not scan arbitrary pages, search/decode opaque references, elevate access or infer that an absent page item is revoked. A minimal candidate is a safe connection display name in the existing use-authorized model metadata response, with stale/revoked/denied tests and a reviewed producer freeze; this is a proposal, not an installed field.
2. **Workflow-bound choice shape/sample.** Standalone authoring has no workflow context or typed input/sample projection. Any shape-aware picker and empty/invalid/valid sample state needs an authorized owning workflow projection and exact version binding. Current permitted-name validation remains useful and truthful.
3. **General retrieval catalog/preview.** There is no safe general source catalog, report-definition `ai_lookup` projection or persisted retrieval-plan preview response. A report's public DTO alone does not authorize offering it as an AI source. Define only the intended supported source/parameters/limit/result schema with authorization, versions, bounds and a non-executing preview. Do not add arbitrary source text, private definition enumeration or unrestricted query/SQL controls to bridge this gap.
4. **Standalone provider test.** No approved standalone agent-draft execution/evaluation route is established. Local checks are the supported mode. Future execution must expose deliberate exact inputs, approval/lifecycle rules, safe evidence and the existing governed execution owner.

The current frontend slice can be locally verified while these narrower contract capabilities remain blocked. Neither historical D07 SDK exceptions nor a fixture-backed browser pass establishes full demo or integrated completion.
